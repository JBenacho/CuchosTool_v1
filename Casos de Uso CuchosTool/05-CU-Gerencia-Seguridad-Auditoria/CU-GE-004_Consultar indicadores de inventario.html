1. Información General
ID / Código: CU-GE-004[cite: 2]
Trazabilidad: RF-GE-004, BL-074, BR-02, BR-03[cite: 2]
Nombre: Consultar indicadores de inventario[cite: 2]
Objetivo: Presentar indicadores agregados de inventario (stock total, valorización, rotación y alertas de agotados) bajo control ABAC[cite: 2].
Actor Principal: GERENTE_GENERAL / GERENTE_ZONA[cite: 2]
Actores Sec.: BFF Router, Cloud SQL (Read Replica), Pub/Sub
Tipo / Prioridad: Consulta Gerencial Prioridad Alta / Esencial[cite: 2]
Estado / Alcance: Aprobado / Solo Lectura (Baseline v6.0)
Disparador: Petición HTTP GET /api/v1/gerencia/inventario desde la SPA corporativa[cite: 2].
Precondiciones: 1. JWT activo con firma válida[cite: 2].
2. ZoneId verificado para GERENTE_ZONA bajo Default Deny.
Postcondiciones: Registro de AuditEvent; cero alteraciones sobre stock físico o reservas[cite: 2].
Resultado: HTTP 200 OK + Payload JSON (InventarioIndicadoresDTO)[cite: 2].
2. Diagrama de Casos de Uso (UML)
3. Descripción y Alcance

Propósito: Ofrecer analítica del estado de inventario: stock disponible consolidado, rotación de existencias, valorización total y alertas de quiebre[cite: 2].

Acceso: Exclusivo mediante JWT válido y filtrado zonal automático bajo Default Deny.

Frontera ERP: Módulo de solo lectura. No genera ajustes de inventario, no ejecuta salidas/entradas de bodega ni modifica reservas atómicas[cite: 2].

4. Reglas de Negocio (RN)
  • RN-GE-01: Autorización obligatoria ABAC por rol y ZoneId bajo política Default Deny.
  • RN-GE-02: Restricción de bodega: GERENTE_ZONA consulta únicamente centros de distribución de su jurisdicción; GERENTE_GENERAL accede al inventario nacional.
  • RN-GE-03: Valorización total consolidada en COP (Pesos Colombianos) sin revelar secretos comerciales ni costos de proveedor[cite: 2].
  • RN-OPS-012: SLA de latencia agregada p99 en Cloud Run ≤ TBD ms (Ref. BL-080 / ARQ v6.0).
5. Flujo Principal (Camino Feliz)
1
Solicitud SPA: Gerente accede a la sección de inventarios; cliente emite GET /api/v1/gerencia/inventario con Bearer JWT[cite: 2].
2
Intercepción BFF: Gateway comprueba el token y propaga cabeceras de observabilidad X-Correlation-ID.
3
Control ABAC: Validador verifica permisos y acota la consulta a las bodegas pertenecientes a ZoneId.
4
Ruteo a Microservicio: Petición enviada a Gerencia Service en Google Cloud Run.
5
Consulta Agregada: Servicio ejecuta consultas SELECT sobre réplicas de Cloud SQL (stock físico y disponible).
6
Estructuración & Auditoría: Consolidación de InventarioIndicadoresDTO y publicación de AuditEvent en Pub/Sub.
7
Entrega 200 OK: Retorno de HTTP 200 OK con el dataset de inventario para graficar en UI[cite: 2].

9. Datos Utilizados y DTO
  • InventarioIndicadoresDTO: DTO analítico agregado de existencias y rotación[cite: 2].
  • totalUnidadesStock: Cantidad física total disponible en almacenes.
  • valorInventarioCOP: Valorización del inventario valorado a costo promedio en COP[cite: 2].
  • tasaRotacion: Ratio mensual de rotación de inventarios por categoría.
  • skusCriticosCount: Conteo de productos con stock por debajo del umbral mínimo.
  • ZoneId / X-Correlation-ID: Jurisdicción zonal y trazabilidad en logs.
10. Criterios de Aceptación (DoD)
  • ✓ Autenticación JWT y validación ABAC bajo Default Deny (BL-019/020).
  • ✓ Operación estrictamente de solo lectura; sin movimientos físicos ni reservas.
  • ✓ Latencia p99 en Cloud Run verificada / TBD documentado (BL-080).
  • ✓ Pruebas negativas de aislamiento de bodegas entre zonas aprobadas (FA-01..05).
  • ✓ Emisión obligatoria de AuditEvent sin registrar datos de tarjetahabientes ni PII.
