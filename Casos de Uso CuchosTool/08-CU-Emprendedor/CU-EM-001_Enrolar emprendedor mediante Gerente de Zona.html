CU-EM-001 - Enrolar emprendedor mediante Gerente de Zona

Proyecto: CuchosTool.com | Baseline: SRS v5.0 / ARQ v6.0 / BL v5.0
Módulo: Emprendedores / Enrolamiento / DOM-EM | Fecha: 02/09/2026
Responsable: Nicola | Rol: Arquitecto & Dirección Técnica
1. INFORMACIÓN GENERAL
ID / Código: CU-EM-001
Trazabilidad: EM-01, RNF-001, BL-001, BR-02
Nombre: Enrolar emprendedor mediante Gerente de Zona
Objetivo: Registrar formalmente a un nuevo emprendedor en la plataforma CuchosTool bajo la supervisión y validación del Gerente de Zona asignado.
Actor Principal: Gerente de Zona (User Role)
Actores Sec.: API Gateway, Cloud SQL, Notification Svc, Audit Svc
Tipo / Prioridad: Emprendedores / Core Prioridad Esencial
Estado: Aprobado / Gestión de Emprendedores (Baseline v6.0)
Disparador: Acceso del Gerente de Zona al formulario de enrolamiento en el portal administrativo.
Precondiciones: 1. Sesión activa con rol ZONAL_MANAGER.
2. Datos básicos del emprendedor validados.
Resultado: HTTP 201 Created / Emprendedor registrado en estado ENROLLED.
2. DIAGRAMA DE CASOS DE USO (UML)
3. DESCRIPCIÓN Y ALCANCE

Propósito: Permitir al Gerente de Zona dar de alta a un nuevo emprendedor recolectando sus datos básicos de identificación y ubicación.

Acceso: Exclusivo para usuarios con rol Gerente de Zona bajo política Default Deny.

Frontera ERP: Módulo de gestión de emprendedores; aislado de transacciones de pagos y DIAN.

4. REGLAS DE NEGOCIO (RN)
  • BR-02 / RN-EM-001: Default Deny estricto en el registro de emprendedores sin validación de zona asignada.
  • RN-EM-002: El número de documento de identidad debe ser único en la base de datos de CuchosTool.
  • RN-OPS-012: Tiempo de respuesta del alta p99 ≤ TBD ms.
5. FLUJO PRINCIPAL (CAMINO FELIZ)
1
Gerente de Zona accede al portal y selecciona la opción "Enrolar Nuevo Emprendedor".
2
El sistema valida el rol de autenticación y permisos sobre la zona geográfica.
3
El Gerente ingresa datos personales, contacto, correo y zona asignada.
4
Validación de unicidad del documento de identidad en Cloud SQL.
5
Persistencia atómica del registro del emprendedor en estado inicial ENROLLED.
6
Envío de notificación de bienvenida con credenciales temporales vía Notifier Svc.
7
Retorno de confirmación de registro exitoso (HTTP 201 Created).
