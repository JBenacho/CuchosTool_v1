CU-EM-006 - Configurar medio de pago electrónico para dispersión

Proyecto: CuchosTool.com | Baseline: SRS v5.0 / ARQ v6.0 / BL v5.0
Módulo: Emprendedores / Pagos / DOM-EM | Fecha: 02/09/2026
Responsable: Nicola | Rol: Arquitecto & Dirección Técnica
1. INFORMACIÓN GENERAL
ID / Código: CU-EM-006
Trazabilidad: EM-06, RNF-001, BL-001, BR-02
Nombre: Configurar medio de pago electrónico para dispersión
Objetivo: Configurar y asociar la cuenta bancaria o medio de pago electrónico del emprendedor para recibir la dispersión de fondos por ventas.
Actor Principal: Emprendedor (Financial Role)
Actores Sec.: Cloud SQL, Payment Gateway API, Audit Svc
Tipo / Prioridad: Emprendedores / Core Prioridad Esencial
Estado: Aprobado / Configuración de Pagos (Baseline v6.0)
Disparador: Acceso del emprendedor a la sección de configuración financiera y de dispersión.
Precondiciones: 1. Emprendedor con estado ACTIVE.
2. Validación de titularidad de cuenta bancaria.
Resultado: HTTP 200 OK / Medio de pago electrónico configurado y validado.
2. DIAGRAMA DE CASOS DE USO (UML)
3. DESCRIPCIÓN Y ALCANCE

Propósito: Registrar la cuenta bancaria o método electrónico del emprendedor para recibir transferencias por dispersión de ventas.

Acceso: Emprendedor autenticado bajo política Default Deny.

Frontera ERP: Módulo de pagos; estrictamente separado de pasarelas de cobro directo y DIAN.

4. REGLAS DE NEGOCIO (RN)
  • BR-02 / RN-EM-011: Default Deny estricto en la dispersión hacia cuentas no verificadas o de terceros.
  • RN-EM-012: Obligatoria la validación de titularidad de la cuenta bancaria frente a los datos del emprendedor.
  • RN-OPS-012: Tiempo de respuesta p99 ≤ TBD ms.
5. FLUJO PRINCIPAL (CAMINO FELIZ)
1
Emprendedor accede a la sección de configuración de pagos electrónicos en su perfil.
2
Ingresa datos de cuenta bancaria o medio de pago electrónico (CLABE / Cuentas).
3
Validación de estructura y formato de cuenta con la API de la pasarela financiera.
4
Persistencia de la configuración de pago en estado verificado en Cloud SQL.
5
Registro de la operación de configuración en el servicio de auditoría (Audit Svc).
6
Notificación de éxito al emprendedor respecto a la habilitación de su cuenta de dispersión.
7
Retorno de confirmación de configuración exitosa (HTTP 200 OK).
